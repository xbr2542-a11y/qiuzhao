# 秋招管家（qiuzhao）

2027 届秋招专用：收集官方投递渠道 → 岗位池筛选排序 → 半自动填表投递 → 状态跟踪。

## 目录结构

```
qiuzhao/
  启动.bat              # 双击启动面板
  自检_浏览器.bat        # 双击验证 Playwright 能驱动本机 Chrome
  docs/                 # 需求分析 / 架构 / 数据库 / 接口 / 实施计划
  app/                  # 后端（Python 标准库 + 少量已装库）
    server.py           # 本地 Web 面板服务
    db.py               # SQLite 结构与访问
    resume.py           # 简历上传与解析
    rules.py            # 专业档位 / 岗位族 / 排序规则
    export.py           # 导出 Excel
    runtime.py          # 定位 Node / Python 运行时路径
    web/                # 前端（无框架）
  workers/              # 采集与填表 worker（Node + Playwright）
  data/                 # 数据库、简历原件、导出文件（全部本地）
  tools/                # 自检与维护脚本
```

## 同步到 GitHub

仓库地址：<https://github.com/xbr2542-a11y/qiuzhao>

**个人数据永远不进仓库**：`data/`（简历原件、岗位库、采集用的 Chrome 配置）和 `.tmp/`
都写在 `.gitignore` 里。这是刻意的设计——岗位库和简历属于个人数据，不该出现在代码仓库里。

| 想做这件事 | 双击 |
| --- | --- |
| 首次把项目接到 GitHub | `上传到GitHub.bat` |
| 平时手动同步一次 | `同步到GitHub.bat` |
| 开启每 15 分钟自动同步 | `开启自动同步.bat`（会弹 UAC） |
| 关掉自动同步 | `关闭自动同步.bat` |
| 浏览器 / git 连不上 github.com | `修复GitHub访问.bat`（会弹 UAC） |

首次上传会弹出 GitHub 登录窗口，需要本人登录一次；之后凭据由 Windows 凭据管理器保存，
自动同步就不再需要登录。同步日志在 `.tmp/github_sync.log`。

关于"自动更新"要说清楚，避免误会：

- GitHub 不会主动读取本机文件。所谓实时更新，是本机计划任务定时 `git push`，
  每 15 分钟检查一次，没有改动就跳过（不产生空提交）。电脑关机时不工作。
- 同步的是**代码**。岗位库每天都在变，但它属于个人数据，不进仓库。

### 附：github.com 打不开时的处理

部分网络会对 `github.com` 做 **DNS 污染**，把域名解析到假地址，导致浏览器和 git
都连不上真站（而真实 IP 是通的）。仓库里附了两个应对手段：

1. `tools/github_net_proxy.py` —— 本机转发：对 `github.com` 改用验证过的真实 IP 建连，
   其余域名照常解析。TLS 仍然是 git 与 GitHub 之间端到端校验，不降低任何安全性
   （对比之下"用 IP 连接 + 关掉证书校验"才是真的不安全）。脚本会自动拉起它。
2. `修复GitHub访问.bat` —— 正规修法：把真实 IP 写进 hosts 文件并刷新 DNS，需要管理员权限。
   修好后浏览器也能正常访问 github.com，此时可以去掉转发配置：
   `git config --local --unset http.https://github.com.proxy`

## 怎么用（三步）

界面只有 4 个页面：**找岗位 / 简历与资料 / 投递记录 / 运行与设置**。

1. **简历与资料**：上传简历（通用版、国际采购版、海外销售版…各传一份），每份简历单独勾「想找什么岗位」；再填专业、学历、意向城市。命令行也可以：
   `python tools/import_resume.py "简历.docx" --name 通用版 --fill-profile`
2. **找岗位**：顶上一排按钮（央国企 / 采购·供应链 / 外贸·海外 / B端销售 / 数据分析 / 半导体）点一下只筛这一类。
   点右上角「找新岗位」会按关键词去国聘、24365、大厂官网、外企官网、公众号这些公开渠道搜索并入库。
   默认按「推荐（对口优先）」排序，把对口且已确认的岗位排在前面；其余条件收在「更多筛选」里。
3. **投递记录**：在岗位详情里点「我投过了，记一笔」并填写依据（申请编号 / 确认邮件时间）。
   **没有依据的状态只会记为「未确认」，不会算成已投递**——程序不会替你假装投过。

### 岗位职能（采购 / 供应链）

岗位识别分两个维度，可以叠加筛选：

- **岗位职能**：采购/寻源、供应链/物流、销售/商务、外贸/国际业务、数据分析、其他。
- **销售类型**：B端解决方案销售、外贸BD销售等（只在销售岗上有值）。

采购、供应链不是销售岗，所以它们不会被"非销售"规则排除；匹配引擎也不会因为
"不是销售岗"就给 0 分。想单独补这一类岗位可以跑：
`python tools/collect_procurement_supply.py --limit 20`

## 岗位来源

目前接入三个来源，合计 **4900+ 条真实岗位**：

**24365 国家大学生就业服务平台（教育部）**——国家平台，民营企业岗位最多：

```
GET https://job.ncss.cn/student/jobs/jobslist/ajax/?jobName=关键词&offset=页码&limit=20
详情 https://job.ncss.cn/student/jobs/{jobId}/detail.html
```

这个来源的字段里**带专业要求（major）**，是目前做"专业档位"判断最准的数据。

**国聘**（国资委官方招聘平台 `iguopin.com`）——央企、国企及其子公司、混合所有制企业，`robots.txt` 允许抓取，无需登录：

```
POST https://gp-api.iguopin.com/api/jobs/v1/recom-job
```

**外企官网（Workday 招聘系统）**——已核实可用：美光 Micron、恩智浦 NXP、英伟达 NVIDIA：

```
POST https://{tenant}.{host}.myworkdayjobs.com/wday/cxs/{tenant}/{site}/jobs
```

采集默认**全国范围**，不限城市（先用匹配度排序把合适的顶上来，面板里有「只看我的意向城市」开关）。
关键词分两组：对口方向（数据分析/外贸/半导体/销售/石油化工等）+ 通用岗位（管培生/采购/供应链/财务/人力资源等），
用户明确要求不限职业、不限国企，所以池子先做大，再由匹配度筛选。

面板右上角的来源下拉可以选择抓哪一个（国聘 / 24365 / 外企官网 / 全部来源依次抓）。

合规约束写进了代码（`app/collectors/base.py`）：只读公开数据、全局限速 12 次/分钟、不登录、不绕验证码、失败即跳过。
新增来源只需在 `app/collectors/` 下加一个模块并注册到 `REGISTRY`。

命令行直接采集：

```
python tools/collect.py --source guopin --use-profile --limit 30 --reset --ingest
```

## 匹配度怎么算

六个维度加权：技能 30 / 学历 15 / 地点 20 / 经验 10 / 薪资 10 / 方向 15。
其中**专业档位**是跨专业求职的关键：JD 没提专业限制按「专业不限」处理（+35），命中你的专业词按「专业相关」（+25），明确限定别的专业（-70），学历不够扣 55～80。
被扣分的岗位不会消失，卡片上会写明判断依据（鼠标悬停在「专业受限」标签上可看原文）。

## 已知约束

## 任务系统

所有自动化行为都以任务形式运行，可在面板「任务日志」页创建、暂停、恢复、停止、重跑：

```python
from tasks import TaskManager
from handlers import register_all

manager = TaskManager()
register_all(manager)
manager.start()
manager.create("demo.pipeline", {"steps": 20, "step_seconds": 0.3})
```

处理器契约：长循环里调用 `ctx.checkpoint()`（响应暂停/停止）、`ctx.progress()`（上报进度）、
`ctx.log()`（写日志）、发起网络请求前调用 `ctx.rate_limit()`。

## 设计决策（来自需求澄清）

- 投递口径：**半自动**——程序填表并排队，你批量确认后提交，绝不无人值守自动提交。
- 渠道范围：企业自建校招门户 + 高校就业网 + 聚合平台（牛客/应届生等）；综合平台（BOSS/智联等）仅作**只读发现源**，不做自动填表。
- 央国企：单独一条线，走统一平台（国聘 / 24365 / 省人社平台 / 央企自建门户），并单独维护**材料清单**与**在线表单字段库**。
- 城市优先级：东营（走央国企路线）> 济南 > 北京 / 深圳 / 广州 / 成都。
- 简历：支持任意多份版本，每份绑定岗位族，上传时自动解析成字段。
- 筛选规则：专业档位三档制（不限 / 相关 / 明确限定），被过滤的岗位保留"为什么被过滤"的可见理由。
- 大模型：v1 不接入，代码预留开关。
