# 04 · 接口设计

> 阶段 3 交付物之三。统一前缀 `/api`，JSON 收发，HTTP 状态码语义化。

## 1. 通用约定

- 成功：`200 {"ok": true, ...}`
- 业务失败：`400 {"ok": false, "error": "..."}`
- 未授权：`403 {"ok": false, "error": "缺少授权：ai:analyze"}`
- 服务异常：`500 {"ok": false, "error": "<traceback>"}`（本地工具，直接暴露堆栈便于排错）
- 列表接口统一支持 `page`、`page_size`（默认 200，上限 2000）、`sort`
- 写操作返回受影响对象的最新状态，避免前端二次拉取
- 危险操作（删除、批量投递）必须带 `confirm: true`

## 2. 端点清单

### 2.1 配置与档案

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | /api/profile | 读取 / 保存档案（含脱敏视图） |
| GET / POST | /api/settings | 评分权重、限流、AI 参数名 |
| GET / POST | /api/authorizations | 读取 / 授予 / 撤销授权 |
| GET / POST | /api/search-configs | 搜索设置 CRUD |

### 2.2 简历

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | /api/resumes | 上传（base64）+ 自动解析 |
| GET | /api/resumes | 列表 |
| GET / POST | /api/resumes/{id}/facts | 读取 / 修正结构化事实库 |
| POST | /api/resumes/{id}/default | 设为默认版本 |
| DELETE | /api/resumes/{id} | 删除（含文件） |

### 2.3 采集与任务

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/sources | 渠道来源列表（含健康状态） |
| POST | /api/tasks | 创建任务（collect / analyze / track / generate） |
| GET | /api/tasks | 任务列表与进度 |
| POST | /api/tasks/{id}/pause|resume|stop | 任务控制 |
| GET | /api/tasks/{id}/logs | 任务日志 |
| POST | /api/jobs/import | 粘贴 / CSV 导入（已有） |
| POST | /api/jobs/ingest | 采集器回写（已有） |

### 2.4 岗位与分析

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/jobs | 岗位池（筛选 / 排序 / 分页） |
| GET | /api/jobs/{id} | 详情（JD 全文、分析结果、材料清单） |
| POST | /api/jobs/{id}/analyze | 触发单条 AI 分析 |
| POST | /api/jobs/analyze-batch | 批量分析（创建任务） |
| POST | /api/jobs/{id}/score-override | 人工覆写分数 |
| POST | /api/jobs/{id}/status | 更新状态 |

### 2.5 投递与招呼语

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/applications | 投递记录（按状态分组） |
| POST | /api/applications/prepare | 批量准备：选岗位 + 选简历，生成待确认清单 |
| POST | /api/applications/commit | 二次确认后落库 |
| POST | /api/greetings | 为指定岗位生成招呼语 |
| POST | /api/greetings/{id}/regenerate | 重新生成 |
| POST | /api/greetings/{id} | 保存人工编辑 |
| GET | /api/greetings/{id}/export | 导出纯文本供复制 |

### 2.6 HR 回复与定制简历

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/hr-messages | 回复列表（含未读） |
| POST | /api/hr-messages/import | 手动粘贴导入 |
| POST | /api/hr-messages/sync | IMAP 同步（需 track:imap 授权） |
| GET / POST | /api/notifications | 未读通知 |
| POST | /api/tailored-resumes | 依据 JD + 原简历生成草稿 |
| GET | /api/tailored-resumes/{id} | 预览（含未验证句子标记） |
| POST | /api/tailored-resumes/{id}/export | 导出 DOCX / PDF（有未验证句子时拒绝） |

### 2.7 导出与系统

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/export.xlsx | 投递总览导出（已有） |
