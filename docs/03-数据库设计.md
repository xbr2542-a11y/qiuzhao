## 2. 关键表字段

### profile（扩展）

已有：`full_name, school, major, degree, grad_date, political, hometown, phone, email, prefer_cities, extra_json`

新增：`skills_json`（技能与熟练度）、`salary_min / salary_max / salary_unit`、`accept_internship`、`accept_travel`、`accept_relocate`、`target_families_json`（求职方向）、`veteran`（退役大学生士兵，用于命中专项岗位）、`privacy_json`（哪些字段允许发送给 AI）

### jobs（扩展）

已有：`dedupe_key, company, title, city, source, family, channel_type, url, deadline, major_req, major_tier, degree_req, grad_only, salary, match_score, filter_note, status, resume_id, note, is_active, collected_at, updated_at, raw_json`

新增：`jd_text`（岗位描述全文）、`salary_min / salary_max`、`published_at`、`experience_req`、`job_type`（校招 / 实习 / 社招）、`is_veteran_special`、`source_id`、`priority`、`manual_score_override`

去重键保持 `company|title|source` 归一化，`url` 作为兜底键。

### job_analyses（新增）

`id, job_id, provider, model, prompt_version, total_score, dimension_json（六维分与依据）, reason_text, gap_text, risk_text, suggestion_text, fact_ids_json, created_at`

同一岗位可保留多次分析（换权重、换模型后重跑），前端默认展示最新一次，可对比历史。

### resume_facts（新增）

`id, resume_id, fact_id（如 F23）, category（教育 / 服役 / 技能 / 荣誉 / 校园 / 项目）, title, org, role, start_date, end_date, detail, keywords_json, confidence, confirmed`

### tailored_resumes（新增）

`id, job_id, base_resume_id, provider, docx_path, pdf_path, content_json, fact_coverage, unverified_sentences, status（草稿 / 已确认 / 已导出）, created_at`

`unverified_sentences > 0` 时禁止导出最终文件——这是"禁止编造"的硬闸门。

### applications（新增）

`id, job_id, resume_id, greeting_id, channel, status（待投递 / 已投递 / 沟通中 / 简历邀请 / 面试 / 已结束）, applied_at, confirmed_by_user_at, last_action, note`

### greetings（新增）

`id, job_id, version, text, provider, model, fact_ids_json, is_selected, edited_by_user, sent_at, send_mode（复制 / 半自动 / 手动标记）, created_at`

### hr_messages（新增）

`id, application_id, source（imap / manual / platform_visible）, from_addr, subject, body, received_at, is_invite, read, action_required`

### tasks / task_logs（新增）

- `tasks: id, type（collect / analyze / track / generate）, payload_json, status, progress, total, priority, rate_limit_per_min, paused, cancel_requested, started_at, finished_at, error, next_run_at`
- `task_logs: id, task_id, ts, level, module, message, payload_json`

### settings / authorizations（新增）

- `settings: key, value_json, updated_at`
- `authorizations: id, scope, target, granted_at, revoked_at, note`

## 3. 迁移策略

现有库已有 `profile / resumes / jobs / materials / events`。迁移方式：**幂等 DDL + 列存在性检查**（`PRAGMA table_info`），在 `db.init_db()` 中执行；不删表、不改旧列名，用户已有的简历与岗位数据完整保留。
